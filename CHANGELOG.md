# Changelog

Every version is published automatically on the [Releases page](https://github.com/FiTH-g1gGLe/COD-MW4-Config-Tool/releases),
and the tool offers it to you the next time you open it.

## v1.7 - View
- **1.7.2** Tip for OLED / wide-colour monitors: washed-out or over-intense colours are fixed with NVIDIA's *Colour accuracy mode: Accurate*.
- **1.7.1** Camera movement set to **Minimal (25%)**, the lowest the game allows (lower values are snapped back to 25% by the game).
- **1.7.0** **Field of view slider** (90-120) that starts at your current FOV. 1st person camera shake turned down for everyone.
  Announcer and hit marker sliders now start at your current volumes. Idle power saving is no longer set (the game forces it back on).

## v1.6 - Control
- **1.6.1** Rig panel is read-only and detected automatically. **Resolution picker** filled from your monitor's supported modes.
  New **Steam launch options** box. Taller window.
- **1.6.0** **Tick boxes** on every change, plus tick/untick all. Unticked changes are skipped and remembered.

## v1.5 - HUD
- **1.5.1** Minimap **rotation on** for everyone.
- **1.5.0** Decoded the game's binary account settings. **Square minimap**, **magenta enemies** (only if you're still on default red)
  and a **HUD position** slider that pulls the minimap and HUD toward your crosshair.

## v1.4 - Updates
- **1.4.1** Version chip shows **UP TO DATE** or **UPDATE READY**.
- **1.4.0** **Built-in update check.** One click downloads the new version, replaces the files and restarts.
- Automatic releases with download counting.

## v1.3 - Layout
- **1.3.1** Fix for Windows PowerShell 5.1. Tidier labels.
- **1.3.0** Reworked layout: hero header with game badge, *Join the squad* footer, backups in the changes panel,
  *Locked and Loaded* screen when there's nothing to change.

## v1.2 - Tooltips
- **1.2.0** Rich tooltips on every option and every change: what it does, how much it matters, and why that value suits your PC.

## v1.1 - Branding
- **1.1.2** Brand-coloured community buttons.
- **1.1.1** FiTH Gaming logo in the window, icon and banner.
- **1.1.0** Dark FiTH theme and the g1gGLe'z MW4 Performance name.

## v1.0 - First release
- Detects your hardware, patches only the values that matter in the game's own files, validates every value,
  backs up before every change, and restores in one click.
